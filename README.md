# Сервис для обработки документов

Этот проект представляет собой веб-сервис для извлечения текста из различных типов документов, таких как PDF и DOCX. Он использует технологию оптического распознавания символов (OCR) для анализа файлов.

## Технологии

- **Python 3**
- **FastAPI**: Современный веб-фреймворк для создания API.
- **Uvicorn**: ASGI-сервер для запуска FastAPI.
- **Pytesseract**: Инструмент для оптического распознавания символов (OCR).
- **Docker & Docker Compose**: Для контейнеризации и управления сервисами.
- **Pytest**: Для автоматизированного тестирования.

## Как запустить

Проект разработан для запуска в Docker-контейнерах.

1.  **Склонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    cd documents
    ```

2.  **файл `.env`** в корневой директории проекта:
    ```env
    MAX_FILE_SIZE_MB=10
    UUID_TEST_CHECK=your-secret-uuid
    PDF_TIMEOUT=120
    ```
    - `MAX_FILE_SIZE_MB`: Максимальный размер загружаемого файла в мегабайтах.
    - `UUID_TEST_CHECK`: Секретный UUID для эндпоинта health-проверки.
    - `PDF_TIMEOUT`: Максимальное время обработки PDF-файла в секундах.

3.  **Запустите сервисы с помощью Docker Compose:**
    Эта команда соберет Docker-образ и запустит контейнеры в фоновом режиме.
    ```bash
    docker-compose up -d --build
    ```
    Если образ уже собран, можно использовать:
    ```bash
    docker-compose up -d
    ```

4.  Сервис будет доступен по адресу `http://localhost:1337`.

## API

### Обработка документа

- **URL**: `/docshandle/{tg_id}`
- **Метод**: `POST`
- **Описание**: Загружает файл, извлекает из него текст и возвращает результат.
- **Параметры пути**:
  - `tg_id` (integer): Идентификатор (ID пользователя в Telegram).
- **Тело запроса**:
  - `file`: Файл для обработки (multipart/form-data).
- **Пример использования с `curl`**:
  ```bash
  curl -X POST -F "file=@/путь/к/вашему/файлу.pdf" http://localhost:1337/docshandle/12345
  ```
- **Успешный ответ (200 OK)**:
  ```json
  {
    "tg_id": 12345,
    "content": "Извлеченный текст из документа..."
  }
  ```

### Проверка состояния сервиса (Health Check)

- **URL**: `/health/{uuid}`
- **Метод**: `GET`
- **Описание**: Проверяет, работает ли сервис.
- **Параметры пути**:
  - `uuid` (string): Секретный UUID, указанный в `.env` файле (`UUID_TEST_CHECK`).
- **Пример использования с `curl`**:
  ```bash
  curl http://localhost:1337/health/your-secret-uuid
  ```
- **Успешный ответ (200 OK)**:
  ```json
  {
    "message": "OK"
  }
  ```

## Тестирование

Для запуска тестов выполните следующую команду:

```bash
docker-compose run --rm test
```
Эта команда запустит отдельный контейнер, который выполнит тесты с помощью `pytest` и затем будет удален.
